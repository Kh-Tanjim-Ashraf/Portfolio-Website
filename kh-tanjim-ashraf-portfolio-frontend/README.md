## Tech Stack

- React 18 + Vite
- react-router-dom v6 (_routing_)
- axios (_single configured instance_)
- TanStack React Query for all server data (_queries + mutations_)
- Context API for auth state (_and for theme_)
- Styling: CSS Modules
- Icons: react-icons or lucide-react
- Optional: react-hook-form, zod/yup, react-hot-toast / sonner, framer-motion react-markdown, a rich-text editor (_Jodit / TipTap / Quill_)
